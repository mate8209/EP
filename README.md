# EP26 · Presentación radical ajustada

Versión web para GitHub Pages con diseño moderno y ajustes de encuadre.

## Cambios principales
- Sidebar convertido en índice desplegable para ganar espacio de pantalla.
- Diapositivas en marco 16:9 más grande.
- Imágenes densas ampliadas y con `object-fit: contain` para evitar recortes.
- Reencuadre de slides visuales: plan de estudios, tweet de agua, sistema de aulas, IA, Boserup/Simon, productividad, causas de muerte y ejemplos positiva/normativa.

## Uso
Subir a la raíz del repositorio:
- `index.html`
- `styles.css`
- `script.js`
- carpeta `img/`

Luego abrir GitHub Pages y forzar recarga con `Ctrl + F5`.

## Controles
- Flecha derecha / espacio: avanzar
- Flecha izquierda: retroceder
- M: abrir/cerrar índice
- F: pantalla completa
