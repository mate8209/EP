# EP26 · Presentación radical nueva

Versión web completa para GitHub Pages.

## Uso
Subir estos archivos al repositorio:

- `index.html`
- `styles.css`
- `script.js`
- carpeta `img/`

Luego abrir GitHub Pages y forzar recarga con `Ctrl + F5`.

## Controles
- Flecha derecha / espacio: avanzar
- Flecha izquierda: retroceder
- M: abrir/cerrar índice
- F: pantalla completa
